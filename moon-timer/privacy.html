소개개인정보처리방침이용약관

1. 기본 원칙

PLOTIVE Moon Timer(이하 "앱")는 사용자의 컴퓨터에서 동작하는 데스크톱 프로그램입니다. 앱을 만든 사람(이하 "운영자")은 별도의 서버를 두지 않으며, 사용자의 기록이나 개인정보를 운영자에게 보내거나 보관하지 않습니다.

2. 앱이 다루는 정보

집필 기록날짜, 집필·퇴고·구상 시간, 추정 글자 수, 작품·회차 이름, 목표, 쉬는 날, 뽀모도로 개수. 사용자의 컴퓨터에만 저장됩니다.
저장하지 않는 것원고 내용, 입력한 글자, 창 제목, 클립보드. 자동 측정은 키를 눌렀다는 사실과 집필 프로그램이 맨 앞에 있는지만 이용하며, 무엇을 입력했는지는 기록하지 않습니다.
구글 계정 정보구글 스프레드시트 연동을 켠 경우에만, 연결된 계정을 화면에 보여 주기 위해 이메일 주소를 받습니다. 로그인 정보(토큰)는 사용자의 컴퓨터에 운영체제 기능으로 암호화해 저장합니다.

3. 구글 사용자 데이터 이용

사용자가 앱 설정에서 "구글 계정 연결"을 누르면 앱은 다음 권한만 요청합니다.

  • drive.file: 앱이 만든 파일에 한해 확인·수정·생성. 앱은 사용자의 구글 드라이브에 "문타이머 집필 기록" 스프레드시트를 만들고, 그 시트에만 하루 작업량을 씁니다. 다른 드라이브 파일은 볼 수 없습니다.
  • openid, email: 연결된 계정의 이메일 주소를 앱 화면에 표시.

앱이 시트에 쓰는 내용은 2절의 집필 기록 항목뿐이며, 이 정보는 사용자 본인의 구글 드라이브에만 저장됩니다. 운영자는 이 정보를 받거나 볼 수 없습니다. 구글 사용자 데이터를 광고, 판매, 다른 서비스로의 전달, 인공지능 학습에 쓰지 않습니다.

PLOTIVE Moon Timer's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. 다른 연동

  • 시간 연동하기: 사용자가 고른 폴더(예: 구글 드라이브·원드라이브 동기화 폴더)에 기록 파일을 씁니다. 앱이 직접 인터넷에 접속하지 않습니다.
  • PLOTIVE 연동: 같은 컴퓨터의 PLOTIVE와 파일로 신호를 주고받습니다. 원고 내용은 주고받지 않습니다.

5. 보관과 삭제

  • 집필 기록은 사용자가 앱을 지우거나 기록 폴더를 지울 때까지 사용자의 컴퓨터에 남습니다.
  • 앱 설정의 "연결 끊기"를 누르면 구글 로그인 권한을 취소하고 컴퓨터에 저장된 로그인 정보를 지웁니다. 구글 계정의 서드파티 액세스에서도 언제든 권한을 취소할 수 있습니다.
  • 앱이 만든 스프레드시트는 사용자의 구글 드라이브에 남으며, 사용자가 직접 지울 수 있습니다.

6. 제3자 제공

운영자는 사용자의 정보를 제3자에게 제공하지 않습니다. 구글 스프레드시트 연동을 켠 경우 데이터는 Google LLC의 서비스(구글 드라이브·스프레드시트)에 저장되며, 구글의 개인정보처리방침이 적용됩니다.
